Condition 1 operator:
  1) Equals — string equals. Example: header User-Agent equals prod
  2) Not Equals — string not equal. Example: header User-Agent not_equals prod
> 3) Contains — substring present (case-insensitive). Example: header User-Agent contains debug
  4) Not Contains — substring not present. Example: header User-Agent not_contains debug
  5) Starts With — string starts with. Example: header User-Agent starts_with prefix
  6) Not Starts With — string does not start with. Example: header User-Agent not_starts_with prefix
  7) Ends With — string ends with. Example: header User-Agent ends_with suffix
  8) Not Ends With — string does not end with. Example: header User-Agent not_ends_with suffix
  9) Matches — regex matches (case-insensitive). Example: header User-Agent matches ^[A-Za-z0-9]+$
  10) Not Matches — regex does not match. Example: header User-Agent not_matches ^[A-Za-z0-9]+$
  11) In — value is in list (comma or pipe separated). Example: header User-Agent in a,b,c
  12) Not In — value is not in list. Example: header User-Agent not_in a,b,c
  13) Exists — value present / header exists. Example: header User-Agent exists -
  14) Not Exists — value missing / header not present. Example: header User-Agent not_exists -
