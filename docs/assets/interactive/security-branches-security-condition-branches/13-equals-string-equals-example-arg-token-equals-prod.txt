Condition 2 operator:
> 1) Equals — string equals. Example: arg token equals prod
  2) Not Equals — string not equal. Example: arg token not_equals prod
  3) Contains — substring present (case-insensitive). Example: arg token contains debug
  4) Not Contains — substring not present. Example: arg token not_contains debug
  5) Starts With — string starts with. Example: arg token starts_with prefix
  6) Not Starts With — string does not start with. Example: arg token not_starts_with prefix
  7) Ends With — string ends with. Example: arg token ends_with suffix
  8) Not Ends With — string does not end with. Example: arg token not_ends_with suffix
  9) Matches — regex matches (case-insensitive). Example: arg token matches ^[A-Za-z0-9]+$
  10) Not Matches — regex does not match. Example: arg token not_matches ^[A-Za-z0-9]+$
  11) In — value is in list (comma or pipe separated). Example: arg token in a,b,c
  12) Not In — value is not in list. Example: arg token not_in a,b,c
  13) Exists — value present / header exists. Example: arg token exists -
  14) Not Exists — value missing / header not present. Example: arg token not_exists -
