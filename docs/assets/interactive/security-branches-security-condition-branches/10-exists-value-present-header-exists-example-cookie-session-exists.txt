  2) Not Equals — string not equal. Example: cookie session not_equals prod
  3) Contains — substring present (case-insensitive). Example: cookie session contains debug
  4) Not Contains — substring not present. Example: cookie session not_contains debug
  5) Starts With — string starts with. Example: cookie session starts_with prefix
  6) Not Starts With — string does not start with. Example: cookie session not_starts_with prefix
  7) Ends With — string ends with. Example: cookie session ends_with suffix
  8) Not Ends With — string does not end with. Example: cookie session not_ends_with suffix
  9) Matches — regex matches (case-insensitive). Example: cookie session matches ^[A-Za-z0-9]+$
  10) Not Matches — regex does not match. Example: cookie session not_matches ^[A-Za-z0-9]+$
  11) In — value is in list (comma or pipe separated). Example: cookie session in a,b,c
  12) Not In — value is not in list. Example: cookie session not_in a,b,c
